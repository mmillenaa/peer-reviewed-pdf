# Revisar e Numerar PDF 📄

Uma ferramenta web leve e de código aberto, projetada especificamente para o fluxo de revisão acadêmica e correção de trabalhos. Executada 100% no lado do cliente (navegador), garantindo total privacidade dos documentos manipulados.

## 🎯 O Problema que Resolve
Ferramentas tradicionais de leitura de PDF dificultam a numeração de linhas de documentos já finalizados e costumam ocultar comentários em pop-ups. Este aplicativo automatiza a numeração de linhas e exporta um PDF revisado com uma margem lateral expandida, ancorando os comentários visualmente ao lado do texto, simulando a experiência do "Control de Alterações" do Word.

## ✨ Principais Funcionalidades
*   **Numeração Automática de Linhas:** Detecta as linhas de texto do PDF original e adiciona numeração na margem esquerda.
*   **Anotações Visuais:** Grifar, sublinhar e tachar textos.
*   **Comentários Ancorados:** Adicione comentários que geram caixas de texto com linhas de conexão até o grifo.
*   **Exportação Inteligente:** Expande fisicamente a largura do PDF no momento do download para acomodar os comentários sem cobrir o texto original.
*   **Zero Backend:** Feito com HTML, JS, TailwindCSS, `pdf.js` e `pdf-lib`. Nenhum arquivo é enviado para servidores externos.

## 🚀 Como Usar
Basta clonar o repositório e abrir o arquivo `index.html` em qualquer navegador moderno. Nenhuma instalação ou servidor local é necessário.

# Peer-Reviewed PDF App 📄

A lightweight, open-source web tool designed specifically for academic peer review and student grading workflows. It runs 100% client-side (in the browser), ensuring complete privacy for the documents being handled.

## 🎯 The Problem it Solves
Traditional PDF readers make it incredibly difficult to add line numbers to finalized documents and often hide comments inside clickable pop-ups. This app automates line numbering and exports a revised PDF with an expanded side margin, visually anchoring comments next to the text (similar to MS Word's "Track Changes" experience).

## ✨ Key Features
*   **Automatic Line Numbering:** Detects text lines in the original PDF and adds numbers to the left margin.
*   **Visual Annotations:** Highlight, underline, and strikethrough text natively.
*   **Anchored Comments:** Add side comments that generate text boxes with connection lines pointing directly to the highlighted text.
*   **Smart Export:** Physically expands the PDF's width upon download to accommodate comments without overlapping the original text.
*   **Zero Backend:** Built with HTML, JS, TailwindCSS, `pdf.js`, and `pdf-lib`. No files are ever sent to external servers.

## 🚀 How to Use
Simply clone the repository and open the `index.html` file in any modern web browser. No installation, dependencies, or local server required.
